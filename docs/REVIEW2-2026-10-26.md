## 本轮发现与修复

| 已复现问题 | 具体影响 | 实施修复 |
| --- | --- | --- |
| DOI 翻译器发现阶段的超时只结束等待，没有退役原任务 | `getTranslators()` 迟到后仍会调用 `translate()`，产生不必要的后续请求 | 每次解析维护独立活动标志；超时、取消或完成后退役；发现及解析返回时均检查活动状态 |
| 清理列表时保留虚拟窗口起点 | 从已滚动的 2000 条列表切换到 500 条列表，顶部却只显示第 500 条 | `clear()` 清理视口、当前列表回调和虚拟计数；新文献从第一条显示 |
| 刷新后列表变短时起点仅限制到最后一条 | 2000 条缩至 300 条后只挂载最后一张卡片 | 渲染和滚动统一限制到最后完整的 60 条窗口，尾部滚动能稳定下来 |
| 筛选仍沿用完整文献表的无障碍位置/数量 | 搜索只剩一项时，DOM 仍报告原来的位置和 2000 项总数 | 按当前筛选集合设置 `aria-posinset` / `aria-setsize`，同时保留原始文献编号；长短列表均覆盖 |
| 目标库等前置错误未进入本地化错误分类 | 只读目标显示 `This library is read-only`，与其他导入失败提示不一致 | 使用现有 `destination` 错误类别，卡片、批量菜单及图谱统一映射本地化提示，技术诊断仍保留 |

无障碍属性按当前集合定义处理，依据 [WAI-ARIA 1.2 的 aria-posinset](https://www.w3.org/TR/wai-aria-1.2/#aria-posinset) 和 [aria-setsize](https://www.w3.org/TR/wai-aria-1.2/#aria-setsize)。验收检查真实 Zotero DOM 和键盘行为，不代表已完成 Narrator/NVDA 的语音朗读验收。

活动标志阻止失效发现结果启动新的解析阶段，并阻止迟到结果继续使用。对于超时前已经启动的宿主翻译器网络传输，本轮没有证明可以强制中止；元数据解析仍使用 `libraryID: false` 与 `saveAttachments: false`，迟到结果不能生成条目。

## 导入与数据保护保持一致

“添加到本地”继续使用规范化 DOI → 本地查重 → Zotero 原生 DOI/Search 翻译器 → 返回 DOI 与标题核验 → 同一事务内再次查重并保存。无 DOI 且没有本地匹配时提供明确提示，不创建简略空条目。批量、卡片与图谱共用此链路。

前两轮建立的分类快照、事务原子性、所有权日志、用户编辑保护、跨窗口取消归属和本地撤回刷新仍保留。Semantic Scholar 官方 Academic Graph API 的来源角色及 Crossref/OpenAlex/出版商/PDF 的关系方向和证据边界未改变。没有新增配置、日志格式或身份迁移。
