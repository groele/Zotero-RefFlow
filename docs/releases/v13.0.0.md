# Zotero RefFlow 13.0.0

Released 2026-11-02. Major milestone release elevating RefFlow to commercial-grade robustness, security, and user experience. Comprehensive hardening across preference key namespaces, connected citation graphs, publisher parsing fault tolerance, multi-window detached reader support, read-only library protection, and 100% synchronized trilingual Fluent localization.

## Highlights & Features

1. **Preference Key Namespaces & Connected Papers Integration**:
   - Replaced raw hardcoded preference keys with typed configuration references across `openAlexKey`, `semanticScholarKey`, and `connectedPapersKey`.
   - Integrated personal API token configuration for Connected Papers directly into the Preferences interface (`preferences.xhtml`) under the Online Services group, with automatic fallback and dual-write support for legacy `ConnectedPapers.accessToken`.
   - Declared default preferences in `addon/prefs.js`.

2. **Fault-Tolerant DOM Parsing & Environment Hardening**:
   - Added robust `try ... catch` exception guards around DOMParser handling in `PublisherReferences.parseHTML` and `parseXML`, gracefully absorbing malformed publisher responses without disrupting citation discovery tasks.
   - Guarded `PathUtils.join` within `BatchJournal.filename` across varying host execution environments.
   - Enhanced `Utils.resolveLibraryID` to reliably resolve active reader items in detached reader windows.
   - Hardened `BatchJournal` IOUtils lookup to fall back to global scope when main window is inaccessible.
   - Upgraded window destruction listeners to utilize Gecko native `Services.wm.getEnumerator("")` global window enumerator to thoroughly purge injected styles across detached tabs.

3. **Read-Only Guards & UI Protection**:
   - Enforced strict `isEditable()` checks during reference card render and match updates, preventing modification attempts on read-only group libraries or trashed items.
   - Suppressed intrusive `ProgressWindowSet.closeAll()` calls from tooltip hover handlers to protect long-running host tasks.
   - Neutralized marketing descriptions in view headers into objective, neutral academic descriptions.
   - Added `box-sizing: border-box; contain: paint layout style;` to virtual reference list rows to eliminate scroll jitter.

4. **Trilingual Localization Completeness**:
   - 100% key synchronization across `en-US`, `zh-CN`, and `it-IT` for both `addon.ftl` and `preferences.ftl`.
   - Added missing localized strings for read-only library warnings, graph toggles, and Connected Papers configuration.
