# Zotero RefFlow 17.0.1

- **On-Demand API Fetching via Sidebar Icon**: Item selection in the Zotero library now loads references strictly from local cache (`cacheOnly: true`, including cross-source cache fallback via `readFallbackCachedReferences`), eliminating automatic API calls or PDF scans when browsing items.
- **Sidenav Icon Activation**: Extracted `src/modules/referenceSidenavTrigger.ts` (`bindReferenceSidenavClick`) so clicking the RefFlow icon in Zotero's right-hand sidenav (or expanding a collapsed RefFlow section) fetches references via API on demand when not yet loaded.
- **Preferences & Tests**: Updated `autoRefresh` Fluent labels across `zh-CN`, `en-US`, and `it-IT`, and added unit tests in `tests/referenceSidenavTrigger.test.ts`.
