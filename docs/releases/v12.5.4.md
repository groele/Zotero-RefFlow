# Zotero RefFlow 12.5.4

Release date: 2026-10-26. The installer includes the reviewed DOI import, data protection, download feedback and card alignment improvements.

## Changes

- Normalize DOI URLs, encoded/full-width text, balanced punctuation and legacy SICI suffixes. Resolve imports through Zotero's native DOI Search translator, verify returned identity, and recheck duplicates inside the write transaction.
- Save the first item, collection, relationships and journal atomically. Preserve the selected parent and captured destination; repeated clicks remain idempotent and failed actions remain retryable.
- Protect edited items, collections, notes and attachments during rollback. Validate nested journal records, read protection evidence after transaction admission, and restore live objects after a failed rollback.
- Keep cancellation scoped to the initiating window. Retire timed-out translator discovery before it can start another metadata request; honor transport cancellers received after request timeout.
- Reset virtual-list positions when changing papers, keep a full bounded tail window after shorter refreshes, and report accessibility positions within filtered results. Localize preflight and rollback errors.
- Report PDF download success and failure independently from metadata imports, count empty attachment responses as failures, and reject empty modern journals without losing recovery markers.
- Align status dots and SVG action icons with the first title line, preserve their size across states, isolate button double-clicks, and scale virtual row heights with text size. Scope card styles to the RefFlow-owned pane.

## Validation

All **301 unit tests** and **140 native leaf scenarios** passed in isolated Windows Zotero **10.0.6** profiles. The native total includes 13 card-layout, 6 source-numbering, 8 attachment/journal detail, 8 lifecycle, 31 protection, 57 import/dataflow and 17 interface scenarios; suite wrappers are excluded. Two import checks used real online native DOI resolution, `10.1038/nphys1170` and `10.1103/PhysRevLett.108.196802`; other fault/permission responses were controlled. The additional PDF check downloads a real synthetic PDF over loopback HTTP into the isolated library. TypeScript checking, production build, tag syntax/version self-check, and ZIP member verification passed. Native file installation from 12.5.3 passed 4 checks; an actual process restart passed 4 further checks, preserving the test item and preferences and validating the real preferences build timestamp.
