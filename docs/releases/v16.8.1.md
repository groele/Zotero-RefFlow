# Zotero RefFlow v16.8.1

## Preferences Pane & Alignment Refinements
- Aligned settings pane controls and descriptions strictly to the 40px golden baseline (`preferences.css`, `preferences.xhtml`): removed unintended indentation on first-row primary controls and double indentation on quick-action checkboxes, and separated `.refflow-subgroup-desc` for subgroup-level descriptions.
- Fixed `notInLibraryOpacity` Fluent rendering on `<html:label>` across `en-US`, `zh-CN`, and `it-IT` catalogues.
- Synchronized `graphView.height` (`"400px"`) bidirectionally with the numeric input in the settings pane (`prefs.ts`).
- Added show/hide visibility toggle buttons for OpenAlex, Semantic Scholar, and Connected Papers API key inputs.
- Added visual disabled-state styling for dependent controls and field cards.

## Core & Reliability Fixes
- Reset `filterMode` to `"all"` on non-preserving pane clears and ensured non-virtual list re-renders reapply active filter modes (`referenceCards.ts`).
- Skipped search index construction when the search query is empty (`referenceCards.ts`).
- Bound reference number click-to-PDF navigation dynamically on live `row.reference` so virtual-list row reuse preserves page-jump behavior (`referenceCardRow.ts`).
- Preserved `x` coordinate when starting new unnumbered bibliography entries so hanging-indent detection works across all entries (`referenceExtractor.ts`).
- Used standard Fluent argument passing for `relatedbox-source-tooltip` (`referencePipeline.ts`).
