# Zotero RefFlow 12.6.0

## Added

- Inspect the selected source, result counts, completeness and provider attempts in the Zotero item pane; configure visibility in settings.
- Use settings-page quick actions for the current item: copy, open, DOI import and batch rollback. Existing sidebar actions remain available.

## Fixed

- Preserve keyboard focus when source details refresh and distinguish retained results from unavailable requests.
- Redact provider diagnostics in the source details and status tooltip.
- Allow importing all references when a search has no matches and generate update release links from the target tag.

## Verification

326 unit tests and production build passed. Seven targeted native scenarios passed in an isolated Windows Zotero 10.0.6 profile, including settings-page import and rollback using controlled DOI metadata. Zotero 11, real online services, actual dark-theme visuals, screen readers and main-profile installation were not verified in this release run.
