# Zotero RefFlow 13.1.4

Released 2026-11-02. UI layout optimization, search placeholder simplification, and Zotero 10-12 forward-looking compatibility range lock.

## Highlights & Updates

1. **Controls Nested inside Source Details (`refflow-source-details`)**:
   - Refactored layout to move reference count, source indicator, and cancellation controls (`#reference-num`, `.header.refflow-status`) directly into the `<details id="refflow-source-details">` container.
   - Cleans up the top area of the sidebar panel, eliminating duplicate and cluttered status rows between the search box and reference cards.
   - When collapsed, users enjoy a pristine view with only the search input and reference cards list; when expanded, comprehensive source diagnostic details, provider attempts, and status indicators are cleanly presented.

2. **Search Placeholder Simplified**:
   - Streamlined the search placeholder from verbose multi-word text to concise and standard terminology across all supported locales:
     - Chinese (`zh-CN`): `搜索`
     - English (`en-US`): `Search`
     - Italian (`it-IT`): `Cerca`

3. **Zotero 10 ~ 12 Platform Compatibility**:
   - Aligned compatibility declarations across `manifest.json`, `update.json`, and `update-template.json` to the standard Flow Series specification:
     - `strict_min_version`: `"10.0"`
     - `strict_max_version`: `"12.*"`
   - Provides native coverage and support for current stable Zotero 10.x, development/preview Zotero 11.x, and future Zotero 12.x architectures.

4. **Localization Robustness & Zero-Regressions**:
   - Enhanced fallback dictionaries to prevent raw Fluent key string leaks.
   - 100% test pass rate across 340 test suites.
