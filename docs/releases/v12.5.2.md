# Zotero RefFlow 12.5.2

Released: 2026-10-22

## Fixed

- Add new local references through normalized DOI identifiers and Zotero's native Search translator. Validate the returned DOI and title before creating an item.
- Report missing DOI, lookup errors, conflicts and timeouts instead of silently creating abbreviated provider-only records. Existing local matches can still be reused; explicit programmatic opt-in remains available for metadata-only creation without a DOI.
- Show lookup progress, specific failures and retryable card actions. Suppress repeated clicks and merge identical pending operations.
- Freeze the destination collections and reference evidence, reject unavailable destinations, avoid empty failed batches, and preserve import ownership and rollback protection.
- Refresh local matches after import without retrieving the online reference list again. Prevent late local matches from overwriting successful import state.
- Preserve Crossref, OpenAlex, Semantic Scholar and PDF source roles and citation direction.

## Installation and compatibility

Install `zotero-refflow.xpi` through Zotero's add-on manager. The add-on identity, stored preferences and Zotero 10.0.6 through 11.* declaration are unchanged. This release's native verification covers Zotero 10.0.6; it does not establish new Zotero 11 coverage.

## Verification

- All 272 automated tests passed, with zero failures or skips. TypeScript and production packaging passed, including rejection of legacy tag formats for new releases.
- An isolated native Zotero 10.0.6 test imported DOI `10.1038/s41586-021-03819-2` using the real DOI translator, verified complete title/creators, reused the existing item on repetition, and located it through the native card.
- Controlled native tests cover missing DOI, conflicts, lookup failure, timeout, cancellation and retry; no user library was modified.
- Exact release package identity and checksums are included in the attached verification report.

## Known limitation

Isolated cold startup can log an `uncaught exception: undefined` diagnostic without a source or stack. The DOI workflow passes native acceptance, but the startup diagnostic remains under investigation; this release does not claim an error-free host log.
