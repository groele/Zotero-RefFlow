# Zotero RefFlow 13.1.2

Released 2026-11-02. Stability and sidebar section title presentation enhancement release.

## Highlights & Fixes

1. **Restore Core Architecture & Native Stability**:
   - Reverted premature monolithic modularization, fully restoring the proven, highly cohesive architecture of v13.0.0.
   - Guaranteed full integrity of the native Zotero 10 Web Component `collapsible-section` ItemPane section, ensuring zero intrusive DOM manipulations.

2. **Refined Section Title & Count Presentation**:
   - Optimized Fluent localization strings across `zh-CN`, `en-US`, and `it-IT` to display clear canonical section titles with parenthesized item counts:
     - Chinese: `参考文献` (when empty/0) / `参考文献（{ $count }）` (when populated)
     - English: `References` (when empty/0) / `References ({ $count })` (when populated)
     - Italian: `Riferimenti` (when empty/0) / `Riferimenti ({ $count })` (when populated)
   - Completely resolved the issue where raw query results overwrote the section title.

3. **Complete Control & Feature Preservation**:
   - Preserved all native section buttons: literature type menu (`refflow-pane-type`), refresh trigger (`refflow-pane-refresh`), and card actions menu (`refflow-pane-more`).
   - Retained canonical colorful feather icon (`reference.svg`), real-time search input (`.refflow-card-search`), data source picker (`.refflow-status`), and comprehensive reference cards with retraction badges and DOI import.

4. **Testing & Verification**:
   - 100% unit test pass rate across all 340 test suites.
