# Zotero RefFlow 12.5.9

Local development candidate; not published.

## Changes

- Add a keyboard-accessible source and completeness disclosure to the Zotero reference sidebar.
- Show the selected source, returned and expected counts when available, partial or complete status, retained earlier results, and provider attempts.
- Render provider diagnostics as text and redact URLs and credential-like values.

## Validation boundary

This candidate does not change the update feed, create a tag or GitHub Release, or install into the user's primary Zotero profile. Native acceptance must run against an isolated Zotero profile and library.
