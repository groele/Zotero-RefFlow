# Zotero RefFlow 16.3.0

- **PDF 阅读器正文引文角标与侧栏双向联动 (Reader ↔ Sidebar Sync)**:
  - 提取引文时自动统计其在 PDF 正文中的提及频次并展示高亮徽标；
  - 侧栏引文卡片展示来源页码，点击即可平滑跳转并定位至 PDF 阅读器对应页码与坐标。
- **关系图谱面板 (Graph Panel) 现代化与国际化对齐**:
  - 全面适配 Zotero 原生 CSS 变量 (`--material-background`, `--material-border`, `--color-accent`)，修复暗色模式 (Dark Mode) 刺眼白条；
  - 消除所有硬编码英文文本，全面接入 Fluent 国际化多语言体系，三语对称补齐 17 个关键词条。
- **批量入库与并发性能打磨 (Batch Importer & Performance)**:
  - 支持无 DOI 引文自动联邦补全入库 (`resolveMissingDOI`)，通过标题、第一作者与年份联邦检索 CrossRef / OpenAlex 补齐元数据；
  - 新增馆藏内存映射索引 (`LibraryMatchIndex`)，按文库与分代隔离缓存，实现毫秒级重复检索匹配加速。
- **增强主流英文引文格式 (APA / IEEE / Vancouver / MLA) 结构化解析器**:
  - 新增专用 `WesternCitationParser` 确定性解析主流英文格式，提取作者、标题、期刊、卷期、页码与 DOI；
  - 自动识别并保留 PMID、PMCID、ISBN 等多源标识符。
- **PDF 跨页/双栏断行连字符与特殊排版修复**:
  - 智能合并跨行排版断词，同时保护具有实际语义的复合词（如 `spin-orbit`、`non-convex`、`self-supervised`）；
  - 自动修复与拼接被断行打断的 URL 和 DOI 路径。
- **P0 架构合规与零技术债务守卫 (§5.9)**:
  - 全面解耦解压 `referenceCards.ts` (降至 275 行) 与 `graphPanel.ts` (降至 270 行)；
  - 源码目录下全部 82 个 TypeScript 文件均严格处于 $\le 360$ 行红线安全区，零技术债务。
