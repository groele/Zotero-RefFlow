# Zotero RefFlow 13.1.5

Released 2026-11-02. Read-only item safety guards and Zotero Flow 3-level preferences alignment grid.

## Highlights & Updates

1. **Read-Only Item Guards (`item.isEditable()`)**:
   - Added native `parent.isEditable()` safety checks across reference import and batch rollback workflows (`ReferenceCards`, `Views`).
   - Prevents unintended write attempts when inspecting items inside read-only group libraries or Trash.

2. **Preferences 3-Level Hierarchy Alignment (Standard 4.2 Grid)**:
   - Standardized `.refflow-setting-group` horizontal padding (`16px`), full-bleed summary headers (`margin: -16px; padding: 12px 16px;`), and `24px` (`40px` baseline) indentation for subordinate controls and descriptions.
