# Zotero RefFlow 16.5.0

- **设置面板空间布局现代化与体验重构 (Spatial Layout & Settings Modernization)**:
  - **40px 黄金基准线三级层级严谨对齐**：全面梳理缓存与来源偏好设置面板，将主从复选框（`启用参考文献列表缓存` ➔ `储存 PDF 源` / `储存 API 源`）建立严格的 24px 从属缩进与开关联动；
  - **嵌套卡片化容器体系 (Nested Subcard Containers)**：将松散堆叠的输入项与大段文本解耦，重构为两大职责分明的标准三级嵌套子卡片——「缓存有效期策略」与「存储配额与空间管理」，内边距严格遵循 12px × 14px 标准网格；
  - **微型卡片网格与零折行对齐 (Micro-Field Cards Grid)**：彻底消除之前双列输入项在窄屏下标签断行（如 `（天）`、`（MiB）` 单独折行）和左右高度错位的视觉缺陷；每个输入字段封装为独立微卡片，顶部标题通栏呼吸、底部紧凑输入，支持 580px 窄屏平滑单列响应式折叠；
  - **运行统计与健康状态一体化仪表盘 (Integrated Storage Health Dashboard)**：将动态空间占用指标、轻量索引统计、一键清理过期缓存及本地存储目录入口收拢至专属状态卡片中，消除大段灰字散落的视觉杂乱感；
  - **排除条目类型输入框优化**：重塑自动刷新排除输入行，提供合理的宽度约束（`max-width: 380px`）与等宽字体排印。
- **P0 架构健康与工程合规全量落地 (P0 Architecture & Compliance)**:
  - **动态兼容范围宏注入**：消除 `preferences.ftl` 中写死的版本号，重构为 Fluent 动态参数 `{ $minVersion }–{ $maxVersion }`，构建期自动注入；
  - **界面零硬编码文案与守卫增强**：补齐数据源 `source-pdf` / `source-api` 本地化，架构守卫升级为全局「零字面文案」强校验；
  - **Unpaywall 开放获取链路接通**：新增 `getOAFromUnpaywall(doi, signal)` 接入联邦解析器 `resolveWork`，自动补齐合法 OA 全文 PDF 地址；
  - **三语本地化深度对齐**：补齐 `it-IT` 缺失译文，修复 `notInLibraryOpacity` 占位，关系图谱独立页面完整接入 Fluent 三语字典，移除 22 条硬编码中文兜底；
  - **全自动模块度量防漂移**：构建期动态统计全仓 82 个 TypeScript 源码模块并同步文档与基线，守卫 Check 9 强制断言一致性。
