# Zotero RefFlow 16.7.1

- **文库快筛索引与导入 DOI 校验/回填 (Library Match & DOI Backfill)**: `LibraryMatchIndex.findFastMatch()`、`Utils.searchLibraryItem()` 与 `BatchImporter` 现在统一读取常规 `DOI` 字段及 `extra` 内 `DOI:` 记录；按标题候选匹配时严格拒绝 DOI 冲突条目，单侧缺失 DOI 时强制校验作者/年份证据（无 DOI/年份/作者证据时拒绝盲匹）；对可复用的无 DOI 既有条目自动回填缺失 DOI，并支持通过 `extra` 检索/索引非期刊条目。
- **PDF 失败状态与缓存隔离 (PDF Unavailable Isolation)**: `fetchPdfReferences()` 在附件缺失或 `PDF.getReferences()` 发生非取消异常时显式标记 `status: "unavailable"` 并跳过缓存持久化，避免将提取失败误缓存为长期或短期的 `empty`。
- **确认空列表清理与保留边界 (Empty vs Unavailable Rendering)**: `performReferences()` 与 `fetchNeighborhoodReferences()` 区分确认 `empty` 与 `unavailable`/`partial`——新结果确认为空时清空旧卡片列表与计数，仅在 `unavailable` 或部分结果失败时保留上一份列表。
- **非期刊条目 Extra DOI 降级保存 (Extra DOI Fallback)**: `BatchImporter.makeItem()` 与 `applyItemDOI()` 在目标条目类型不支持原生 `DOI` 字段时将标准化 DOI 写入 `extra`（`DOI: ...`），不再静默丢弃。
- **设置面板联动、重置与本地化对齐 (Preferences Linkage, Reset & l10n)**: 补齐 `autoRefresh` -> 忽略条目类型、`graphView.enable` -> 图谱高度、`isShowTip` -> 8 项浮窗子控件的主从联动（含初始化、偏好观察、`command`/`change` 与恢复默认）；在模块 6 增加“恢复默认设置”按钮（重置常规行为与显示偏好并保留 API 密钥与 CNKI 账号）；将 `preferences.xhtml` 中残留的 `100%`/`px`/`API` 及 `PDF.getReferences()` 进度通知文案全面接入 Fluent trilingual FTL。
