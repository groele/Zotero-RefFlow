# Zotero RefFlow 13.2.0

Release date: 2026-11-04  
Part of Zotero Flow series.

## Major Highlights & Changes (中等版本重大演进)

### 1. 架构深度解耦与 360 行守卫落地 (Architectural Decoupling & <=360 Line Guard)
- **Connected Papers 图谱模块深度解耦**：将原 1,099 行的单体控制器重构拆解为高内聚的领域服务，主协调器精简至 299 行：
  - `graphStyles.ts`：图谱容器与亮暗主题样式注入；
  - `graphViewer.ts`：内嵌 iframe 容器初始化与拉伸调整器 (Resizer)；
  - `graphVisualState.ts`：图谱节点激活与高亮联动状态管理；
  - `graphCard.ts`：单卡片渲染、拖拽交互与操作；
  - `graphPanel.ts`：图谱主面板容器、状态行与工具栏构建。
- **Views 侧边栏与编排流水线模块深度解耦**：将原 1,047 行的单体控制器拆解为专注的领域子服务，主协调器精简至 301 行：
  - `referencePaneStyles.ts`：item-pane 与卡片样式注入；
  - `referenceTip.ts`：多源引文元数据悬浮窗渲染；
  - `referencePaneDOM.ts`：item-pane 容器注册、多窗口自愈与重置；
  - `referenceAttachment.ts`：PDF 附件有效性检查与缓存安全签名；
  - `referenceNeighborhood.ts`：Citations / Related 学术网络多步推断；
  - `referenceSourceFetchers.ts`：Auto / Web / PDF / API 独立检索分支；
  - `referenceRefreshDispatcher.ts`：刷新队列防抖与取消调度；
  - `referenceSettingsAction.ts`：首选项动作与条目交互调度；
  - `referenceBatchOperations.ts`：批量导入关联节点与事务回滚管理；
  - `referencePipeline.ts`：核心引文流水线编排。
- **自动化架构守卫测试 (`tests/architectureGuard.test.ts`)**：
  - 常态化断言所有重构目标模块行数严格 `<= 360` 行；
  - 杜绝任何版本号或临时前缀命名，保持干净的语义化命名；
  - 完整保持 `Views` 与 `ConnectedPapers` 原型链方法与公开 API 的 100% 向后兼容。

### 2. Connected Papers 多起点安全解析与来源透传
- **起点解析统一收敛 (`graphOriginResolution.ts`)**：自动校验并过滤空 ID 或破坏 API 请求键的非法分隔符，支持对有效起点正常构建图谱；
- **状态与来源标明 (`graphStatus.ts`)**：图谱状态栏明确呈现 `Connected Papers` 数据源 Provenance，并准确标注未解析起点数量（如 `未解析起点 1`），避免信息丢失；
- **异步管线解耦 (`connectedPapersPipeline.ts`)**：起点解析、图谱拉取与本地文献匹配彻底解耦，检索失败或无有效起点时提供清晰本地化提示。

### 3. 阅读器与本地化鲁棒性加固
- **阅读器失效附件防护**：检测并阻断针对已删除、移入回收站或不可访问的 PDF 附件提取，避免错配其他附件；
- **Fluent 多语言沙箱作用域穿透定位**：修复原生运行环境中全局作用域缺失导致回退字面键名的问题，增加多层穿透与韧性默认值；
- **右键折叠菜单命令委托**：二级折叠菜单顶层容器统一委托命令下发，保证异步刷新下的选区快照一致性。
