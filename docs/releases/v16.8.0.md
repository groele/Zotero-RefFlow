# Zotero RefFlow 16.8.0

- **导入文献归入当前文献所在子文件夹 (Import into Current Paper's Subcollection)**: 修复 `Utils.importCollections()` 优先读取 `ZoteroPane.getSelectedCollections()` 导致在 PDF 阅读器标签页或递归显示父级文件夹视图下添加参考文献时，新文献被误导入主界面背景选中分类或父级文件夹的问题。现在统一以当前文献自身所属的分类 / 子文件夹（`parent.getCollections()`，若传入附件则自动回溯至主条目 `parentItem`，并去重及过滤已删除或跨文库分类）作为导入目标：
  - 单条点击 `+` 按钮及关系图卡片导入会直接将新文献添加到当前文献所在的子文件夹中（若当前文献未归入任何分类，则保留在文库根目录，不会被背景选中分类吸走）；
  - 右键/设置面板批量导入（启用 `createSubCollection` 时）也会在当前文献所在的子文件夹下创建 `[Refs]` 子分类。
- **回归测试 (Unit Tests)**: 更新并扩展 `tests/doiImport.test.ts` 中的目标分类测试，覆盖 `ZoteroPane` 选中无关分类、未归类条目、已删除/跨文库分类过滤及附件回溯主条目场景。
