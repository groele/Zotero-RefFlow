# Zotero RefFlow 13.1.6

Released 2026-11-03. Comprehensive read-only UI state protection, localized error resolution, ConnectedPapers origin editability guards, and full documentation/version synchronization.

## Highlights & Updates

1. **Complete Read-Only UI & Context Menu Protection**:
   - **Quick-Action Context Menu (`ReferenceCards.menu`)**: Automatically disables `cards-import-selected`, `cards-import-all`, and `relatedbox-rollback` menu items (`disabled="true"`) when the active parent item or library is read-only (`!parent.isEditable()` or non-editable library), preventing invalid user actions upfront in addition to execution-level guards.
   - **Card Action Button & Library Match Sync**: Unified `parent.isEditable()` and library editability checks in both initial card rendering and asynchronous library match updates (`queueLibraryMatch`).
   - **ConnectedPapers Graph Item Action Guard**: Added origin editability validation (`originsEditable`) so graph candidate import buttons automatically disable and display localized read-only tooltips when any graph origin item belongs to a read-only library or Trash.

2. **Localized Read-Only Error Resolution (`Views`)**:
   - Fixed `Views.importReferences` and `Views.rollbackReferences` to invoke the imported `getString('cards-library-readonly')` localization helper directly instead of an undefined `globalThis.getString` lookup, ensuring localized read-only error messages across `zh-CN`, `en-US`, and `it-IT`.

3. **Documentation, Release Notes & Version Consistency Gate**:
   - Synchronized `package.json`, `addon/manifest.json`, `update.json`, `docs/brand/product.json`, `README.md`, and `README.en.md` to version `13.1.6` (`v13.1.6`) and Zotero compatibility range `10.0` – `12.*`.
   - Added automated regression tests in `tests/robustness.test.ts` verifying read-only UI menu disabling, localized `Views` read-only guards, and zero version/documentation drift across repository manifests and READMEs.
