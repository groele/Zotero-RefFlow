# Zotero RefFlow 13.1.1

Released 2026-11-02. Maintenance release addressing sidebar section title presentation and decoupling title from item count.

## Fixes & Improvements

1. **Decouple Sidebar Section Title from Reference Count**:
   - Resolved the issue where the sidebar section title was replaced or overwritten by reference query summary text (e.g. `49 references`).
   - Separated the canonical section title (`Zotero RefFlow 参考文献`) from dynamic count indicators.
   - Refactored `src/modules/views.ts` and `src/modules/views/paneRenderer.ts` to maintain distinct header title labels and item counter containers.

2. **Localization & Fallback Enhancements**:
   - Updated `addon/locale/zh-CN/addon.ftl`, `addon/locale/en-US/addon.ftl`, and `addon/locale/it-IT/addon.ftl` with explicit section title keys and separate count summary formatting.

3. **Automated Test Coverage**:
   - Added unit test suite `tests/sectionTitleSummary.test.ts` to assert that sidebar headers and count labels remain completely isolated and verified.
   - All 26 test suites and 342 unit tests passing.
