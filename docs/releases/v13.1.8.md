# Zotero RefFlow 13.1.8

Released 2026-11-03. Comprehensive settings architecture modularization (5+1 business-driven groups), full preference exposure (Open Access batch download, citation graph controls, CNKI credentials), dead locale key cleanup, and automated preference coverage tests.

## Highlights & Updates

1. **Modular 5+1 Settings Panel Architecture**:
   - Reorganized the preferences window (`preferences.xhtml`) from a scattered layout into a logical top-down flow:
     - **Module 1: Literature Retrieval & Sources** (`open="open"` by default): Priority sources, auto-refresh triggers, PDF/API reference persistence, and source completeness details;
     - **Module 2: Reference List & Card Display**: Library match opacity slider, and Connected Papers citation graph toggle & container height;
     - **Module 3: Hover Preview & Tooltips**: Floating window trigger delay, Ctrl+click translation, background/title colors, and smooth fade durations;
     - **Module 4: Batch Import & Quick Actions**: Automatic Open Access (OA) PDF download toggle, and sidebar quick menu action filters;
     - **Module 5: Online Academic Services & API Keys**: Dedicated credential cards for OpenAlex, Semantic Scholar, Connected Papers, and CNKI;
     - **Module 6: About Zotero RefFlow**: Version badges, attribution licenses, build timestamps, and release links.

2. **Full Core Feature Preference Exposure**:
   - Exposed `downloadOA` (`extensions.zotero.refflow.downloadOA`) in the settings UI to allow users to toggle automated Unpaywall / OpenAlex OA PDF downloads during batch imports;
   - Exposed `graphView.enable` and `graphView.height` to let users control default citation graph visibility and container sizing;
   - Added CNKI username and password credential inputs (`CNKI.username` / `CNKI.password`) for Chinese journal retrieval.

3. **Locale Key Cleanup & Strict 3-Language Parity**:
   - Purged 10 unreferenced legacy keys from `zh-CN`, `en-US`, and `it-IT` localization files;
   - Added complete symmetric translations for all new preference groups and control labels across Chinese, English, and Italian with zero discrepancy.

4. **Automated Preference & Grid Coverage Testing**:
   - Added automated suite in `tests/robustness.test.ts` verifying the 6-group modular structure, default-open state, complete 29-preference binding coverage, and 100% symmetric locale key parity.
