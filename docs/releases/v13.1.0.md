# Zotero RefFlow 13.1.0

Released 2026-11-02. Major architectural refactoring, function-level deep inspection, and modularization release. Decoupled monolithic files (`views.ts`, `connectedpapers.ts`, `api.ts`, `tip.ts`) into dedicated, single-responsibility submodules across UI, Graph, Providers, and Retrieval, while preserving 100% public API compatibility and 100% unit test verification.

## Highlights & Architectural Modularization

1. **Deep Function-Level Inspection & Monolithic Code Decoupling**:
   - **`src/modules/views/settingsActions.ts`**: Extracted setting action dispatchers (`executeSettingsAction`) and error sanitization (`formatSettingsError`) from `views.ts`.
   - **`src/modules/views/paneRenderer.ts`**: Extracted reference pane UI controls (`resetReferencePane`, `cancelReferencePane`, `typeMenu`) from `views.ts`.
   - **`src/modules/views/referencePipeline.ts`**: Extracted multi-level retrieval & fallback pipelines (`onlineReferences`, `smartReferences`, `referenceDescription`) from `views.ts`.
   - **`src/modules/providers/paperInfoProviders.ts`**: Decoupled multi-source response formatters (Crossref, ConnectedPapers, ReadPaper, SemanticScholar, Unpaywall, ArXiv, ReadCube) out of `api.ts`.
   - **`src/modules/providers/cnki.ts`**: Extracted dedicated `CNKIProvider` handling CNKI searches, grid parsing, and credential token renewal out of `api.ts`.
   - **`src/modules/graph/relatedPanelBuilder.ts`**: Decoupled 380+ lines of XUL/HTML panel assembly and origin buttons out of `connectedpapers.ts`.
   - **`src/modules/graph/relatedItemRenderer.ts`**: Decoupled 270+ lines of node item rendering, hover state tracking, and collection import menus out of `connectedpapers.ts`.
   - **`src/modules/ui/tipContentRenderer.ts`**: Decoupled 290+ lines of tooltip DOM rendering, translation click handlers, and bullet pagination out of `tip.ts`.
   - **`src/modules/index.ts`**: Established a unified barrel export index categorizing all 5 architecture layers (UI & Panels, Scholarly Providers, Citation & Verification, Importer & Transactions, Graph & Relationships).

2. **Core Reliability & Headless Environment Defenses**:
   - **`src/utils/locale.ts`**: Fixed `initLocale()` crash when `ztoolkit.getGlobal("Localization")` is undefined in headless/unit testing environments, adding robust fallback mocks.
   - **`src/modules/referenceTextParser.ts`**: Corrected `splitCreator` author parsing for Chinese/single-token author names to assign `lastName`, and improved `isDOI()` token filtering to avoid false positives on CNKI tokens.
   - **Defensive `isEditable()` Safety**: Added optional chaining and type guards (`typeof item?.isEditable === 'function' ? item.isEditable() : true`) in `views.ts` and `referenceCards.ts`, preventing unhandled type errors when operating with diverse Zotero Item mock structures.

## Validation & Test Suite

- TypeScript check (`npm run tsc`): 0 errors.
- Unit suite (`npm test`): 25 suites, 341/341 tests passed (100% pass rate in ~1.3s).
- Production build (`npm run build-prod`): Clean bundle build without warnings.
