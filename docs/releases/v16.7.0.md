# Zotero RefFlow 16.7.0

- **虚拟列表筛选修复 (Virtual Filter Fix)**: 超过 200 条时，空搜索框下筛选模式（未入库/已入库/OA/撤稿）此前被索引短路跳过；`ListIndices` 现在始终应用 `matches`，并在筛选键变化时重建索引。
- **长列表滚动性能 (Scroll Remount + Row Reuse)**: 虚拟窗口滚动改为 `requestAnimationFrame` 合并；稳定引用复用既有卡片 DOM（`rebindReferenceCardRow`），文库匹配状态在滚动中保留。
- **出版商请求缓存治理 (Publisher Cache)**: `PublisherReferences` 改为 `cacheTTL: 0`，不再在每次请求后 `clearCache()` 抬升全局缓存代次，保留 in-flight 去重与共享冷却。
- **批次日志读取批量化 (Batch Journal get)**: `BatchJournal.get` 改为一次 `getAsync([...ids])`，降低撤回核验时的逐条往返。
- **被引/相关来源文案一致 (Neighborhood Source Sync)**: 侧栏标题与来源详情改为同一 `sourceEvidence` 描述，避免 count/expected 漂移。
- **空结果短缓存与离线保留 (Empty Snapshot Retention)**: 确认的空参考文献/被引结果写入短 TTL 快照；短暂 `unavailable` 不会覆盖已确认的 empty。
- **架构**: 抽出 `referenceCardRow.ts` / `referenceCardRebind.ts` / `referenceCardsVirtual.ts`（源码模块 87 个，均 ≤360 行，债务清零不变）。
- **说明**: 本版本承接原计划以 16.6.1 发布的同一批性能与体验修复，正式以 **16.7.0** 作为对外版本身份。
