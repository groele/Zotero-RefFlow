# Zotero RefFlow 16.1.2

RefFlow stores reference lists in `refflow-reference-cache.json` inside the active Zotero data directory. On upgrade, an existing legacy cache is renamed on first use. If both names exist, the current cache takes precedence. Cached data and its retention settings use the existing format.

The Storage section displays the cache file path and opens its containing folder. Complete online, citation, related-work and PDF lists default to 30 days. Existing explicit retention settings take precedence. Partial results default to 15 minutes.
