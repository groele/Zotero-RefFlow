# Zotero RefFlow 12.6.1

A maintenance release improving cancellation, import safety and diagnostic privacy.

- Keep cancellation available for the current item's active import when retrieval finishes, including after switching away and back.
- Require an explicit selection for selected-reference import and explain the requirement.
- Stop cancelled queued imports before legacy journal migration and check cancellation within the migration transaction.
- Redact credential-like values in visible import errors and relevant diagnostic logs.
- Make the isolated native runner skip live publisher checks when offline mode is requested.

## Verification

330 unit tests and the production build passed. Targeted native scenarios passed in an isolated Windows Zotero 10.0.6 profile using controlled services and DOI metadata. Live publisher services, actual dark-theme visuals, Zotero 11 and installation in the primary profile were not verified.
