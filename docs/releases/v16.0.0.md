# Zotero RefFlow 16.0.0

Zotero RefFlow 正式发布 **16.0.0** 大版本，标志着全系统一大版本（Zotero Flow Unified Major Release 16.0.0）协同确立。

## 🌟 核心升级与特性

1. **统一全系大版本号**：跃升至 16.0.0，与 Zotero Flow 家族其余六大插件保持完全一致的版本号与契约；
2. **纯净现代化架构底座**：全仓 72 个 TypeScript 源码模块 100% 恪守 360 行上限约束（0 债务），静态类型检查 100% 通过；
3. **Gecko 153 与 Firefox 140+ 原生对齐**：采用现代 esbuild 构建流水线与冻结内建原型防御插件，确保未来平台长期稳定性；
4. **全量文献发现与网络图谱能力**：深度集成文献关系探测、本地与云端引文发现及交互式文献关系网络图；
5. **双向 Fluent 本地化中英双语严格对称**：设置面板 100% Fluent `data-l10n-id` 驱动，零硬编码。
