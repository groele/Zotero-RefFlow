## Changes

- Resolve Connected Papers origin identifiers independently, omit failed or malformed identifiers, and deduplicate repeated Semantic Scholar identities before requesting a graph.
- Keep graph retrieval available for resolved origins when another selected origin cannot be resolved, and expose the unresolved-origin count in the graph status.
- Show a localized actionable error and skip the remote graph request when no origin can be resolved.
- Add focused regression coverage for partial resolution, duplicate identities, malformed IDs, and cancellation.
- Reject a deleted, trashed, or missing reader PDF without silently extracting from a different attachment.
- Fix Fluent runtime localization lookup across plugin global scopes and provide resilient fallbacks for cards labels, recovery hints, and offline cache status indicators.
- Enable direct command delegation from grouped context menu submenus to preserve snapshot copying under rapid list mutations.
