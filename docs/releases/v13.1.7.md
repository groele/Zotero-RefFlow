# Zotero RefFlow 13.1.7

Released 2026-11-03. Modern Gecko architecture enhancement for detached reader windows, resilient main-window library navigation routing, safe XUL namespace fallbacks, and complete regression test coverage.

## Highlights & Updates

1. **Detached Reader Window Compatibility (Zotero 10 ~ 12 Modern Architecture)**:
   - **Multi-tier Reader Detection (`Utils.getReader`)**: Enhanced reader resolution to seamlessly support detached PDF/EPUB reader windows (where `win.Zotero_Tabs` is absent) by inspecting `win.reader`, `win.ZoteroReaderView.reader`, `Zotero.Reader.getByWindow(win)`, and actively traversing `Zotero.Reader._readers` across frames and top-level detached windows.
   - **Active Item & PDF Reference Parsing**: Ensured `getItem(win)`, `resolveLibraryID(win)`, and `importCollections(parent, win)` reliably extract the active parent item and appropriate library context when invoked from detached reader tabs or windows.
   - **Resilient Library Navigation (`Utils.selectItemInLibrary`)**: Added automated main-window routing and graceful fallback (`Zotero.getMainWindow()` / `Zotero.getActiveZoteroPane()`). Clicking "Locate in Library" (`cards-show-library`) or opening items from a detached reader window safely focuses the main library pane without throwing `TypeError: Cannot read properties of undefined (reading 'select')`.

2. **Safe XUL Element Namespace Fallbacks**:
   - Implemented `Utils.createXULElement(doc, tag)` with strict fallback from `doc.createXULElement` to `doc.createElementNS("http://www.mozilla.org/keymaster/gatekeeper/there.is.only.xul", tag)` and standard `doc.createElement`.
   - Updated popup menus and action buttons in `ReferenceCards.menu`, `Views.typeMenu`, and `ConnectedPapers.registerButton` to prevent execution failures in non-XUL / HTML document contexts.

3. **Preference Grid & Visual Alignment Verification**:
   - Verified that preference panel settings (`preferences.xhtml` & `preferences.css`) adhere strictly to the 2026-11-02 3-level indentation standard (`margin-inline-start: 24px`, card padding `16px`, full-bleed headings `margin: -16px; padding: 12px 16px;`), ensuring smooth responsive wrapping and high contrast theme adaptation.

4. **Automated Regression Test Suite**:
   - Added unit test cases to `tests/robustness.test.ts` covering detached reader window resolution, cross-window library item selection routing, and XUL element creation fallbacks under various document implementations.
