# Zotero RefFlow 16.2.0

Candidate build.

- Add cache capacity settings of 1–64 MiB and 10–10000 papers, defaulting to 8 MiB and 250 papers.
- Show current cache usage, session evictions, expired lists and skipped oversized saves in preferences.
- Remove expired reference snapshots at startup, after retention changes, every ten minutes and through a manual cleanup button. Zero-day retention remains unlimited, subject to capacity eviction.
- Apply capacity changes immediately and prune expired lists before evicting recently used data. Keep reference, PDF and neighborhood retention independent.
- Preserve the existing cache path and library isolation. The per-paper 2 MiB limit continues to apply.
- Write two-space-indented UTF-8 JSON with paper and reference fields on separate lines. Capacity accounting includes indentation and the final newline.

The cache continues to use a bounded JSON file. Shared metadata deduplication and per-paper incremental storage are future work.
