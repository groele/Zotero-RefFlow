# Zotero RefFlow 16.8.4

- **Complete Sidebar Reference Extraction Fix (PDF Two-Column, Scripts, Headings & Backwards Window)**: Fixed `pdfLayout.ts` so right-column references positioned above a lower-left `References` heading are preserved in reading order instead of being discarded before the heading, centered spanning headings keep both columns while flush-right headings stay in column 1, and inline subscripts/superscripts (e.g. `MoS2`, leading superscript citation numbers) preserve reading order and spacing; normalized non-zero PDF `viewRect` origins in `structuredPDF.ts`; supported letterspaced/variant headings, prevented year-in-brackets false splits, and replaced brittle strict `+1` headingless rejection in `referenceExtractor.ts`; relaxed first-page numbering start and extended backwards scan past `80` trailing supplementary pages in `pdf.ts`.
- **Online Completeness & Auto Fallback Hardening**: Updated `api.ts` so uncorroborated small OpenAlex reference sets (`<= 5` items) no longer suppress Publisher/PDF fallbacks when Semantic Scholar returns zero references, widened Auto PDF suspiciously-few fallback thresholds in `referencePipeline.ts`, and bumped cache schema keys (`retrieval-v8`, `pdf-sdt-v5:`) to invalidate prior partial caches cleanly.
- **Graph Viewer Height CSS Unit Fix**: Normalized raw numeric `graphView.height` preference values (`200`–`1600` px) in `graphViewer.ts` and `connectedpapers.ts` so embedded graph containers apply valid CSS heights even after numeric preference edits.
