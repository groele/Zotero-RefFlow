## Major Highlights & Changes (工程架构治理与零欠账达成)

### 1. 全仓 360 行架构硬约束达标与历史欠账彻底清零 (§5.9 Architecture Debt Cleared)
- **4 大历史遗留超长模块深度领域解耦**：将 RefFlow 剩余的 4 个超长模块全量拆解为职责单一、高内聚的子模块，全部降至 360 行基线以下：
  - `src/modules/batchImporter.ts`（424 行 $\to$ 286 行）：将批量导入事务回滚、遗留 Extra 标记迁移与跨条目关系/文集清理逻辑剥离至 `src/modules/batchRollback.ts`（202 行）；
  - `src/modules/utils.ts`（517 行 $\to$ 280 行）：将 DOI/arXiv/URL 正则提取、GB/T 7714 解析分发、作者姓名拆分与 HTML 清理逻辑抽取至 `src/modules/referenceParser.ts`（241 行）；
  - `src/modules/tip.ts`（567 行 $\to$ 139 行）：将引文浮层 DOM 节点工厂（标题/标签/操作/摘要）抽离至 `src/modules/tipDOM.ts`（303 行），视口边界自适应与滚轮缩放抽离至 `src/modules/tipView.ts`（186 行）；
  - `src/modules/api.ts`（694 行 $\to$ 320 行）：将知网（CNKI）检索、网页抓取与阅读 API 独立收敛至 `src/modules/cnkiProvider.ts`（184 lines），将多源引文适配转换器（Crossref/OpenAlex/arXiv/ConnectedPapers 等）抽离至 `src/modules/apiMappers.ts`（232 行）。
- **72 个源码文件 100% 达成 360 行基准**：
  - 扫描全仓 `src/` 下全部 72 个 TypeScript 源码模块，超长模块数正式降为 **0**；
  - `scripts/architecture-baseline.json` 宣告 `debtCleared: true`，历史冻结名单清空为 `{}`；
  - 架构守卫常态化校验 `freeze-and-shrink` 基线完整性，禁止任何模块反弹反向膨胀。
