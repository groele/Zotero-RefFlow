发布版本：10.0.0。GitHub 标签：`V10`。日期：2026-10-14。

维护者要求将此前 11.0.3 本地候选版重新编号为 V10。插件名称、ID `refflow@groele.github.io`、功能及 Zotero `10.0.6–11.*` 兼容范围保持一致。构建清单、更新清单、package / lockfile、README、版本说明及更新详情链接同步使用本版本。

## 安装

先停用旧 RefNexus，再安装 RefFlow；新 ID 不会通过旧 ID 自动更新。首次启动复制旧用户设置，保留原配置和批次导入日志格式。已安装同 ID 的 11.0.3 本地候选包时，需手动从文件安装 10.0.0，自动更新不会降级。
